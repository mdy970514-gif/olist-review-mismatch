# 리뷰 텍스트와 별점의 불일치 탐지 (Olist 브라질 이커머스)

자동 평가(기계번역 + 감성 판정)가 사람이 직접 남긴 평가(별점)와 얼마나 일치하는지 확인하고, 둘이 어긋나는 리뷰와 판매자를 찾아낸 개인 프로젝트입니다.

## 데이터
- Olist Brazilian E-Commerce Public Dataset (Kaggle 공개 데이터)
  - https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- 리뷰 99,224건, 판매자 684명, 고객 95,380명
- 원본 CSV는 용량 문제로 저장소에 포함하지 않았습니다. 위 링크에서 내려받아 같은 폴더에 두면 노트북을 실행할 수 있습니다.

## 분석 흐름
1. 포르투갈어 리뷰를 deep-translator(Google 번역)로 영어로 번역 (무작위 샘플 3,045건)
2. 번역된 리뷰에 VADER 감성 판정 적용
3. 감성 판정을 별점(사람 평가)과 별점 구간별로 대조
4. 규칙 기반 감성사전과 로지스틱 회귀, 랜덤포레스트로 별점과 텍스트가 어긋나는 리뷰를 탐지
5. 불일치 정도를 판매자 단위로 모아 위험 판매자를 분류

## 핵심 결과
- 별점 1점 리뷰 중 VADER가 부정으로 판정한 비율은 40.8%에 그쳤습니다. 자동 판정과 사람 평가가 크게 어긋나는 구간이 있다는 뜻입니다.
- 별점과 리뷰 내용이 어긋나는 리뷰 1,309건을 선별해, 전수 검토 대비 검토 대상을 98.7% 줄였습니다.
- 판매자 684명을 경고 13명, 관찰 64명, 정상 607명으로 분류했습니다.
- 불일치 탐지 모델 Test AUC: 로지스틱 회귀 0.629, 랜덤포레스트 0.621

## 한계
- 번역 과정에서 뉘앙스가 바뀔 수 있고, VADER는 영어 원문 기준 감성분석기라 번역문에서는 판정이 달라질 수 있습니다.
- 감성사전은 직접 구성한 규칙 기반이라 편향 가능성이 있습니다.
- 그래서 자동 판정을 정답으로 보지 않고, 사람 평가(별점)와의 불일치 자체를 분석 대상으로 삼았습니다.
